# Web font licenses

The bundled Manrope and Noto Sans web fonts are distributed under the SIL Open Font License 1.1. The license text is available in `OFL-1.1.txt`.

Noto Sans Georgian Variable, Noto Sans Armenian Variable, and Noto Sans Devanagari Variable were sourced from the corresponding Fontsource packages, version 5.3.0:

- `@fontsource-variable/noto-sans-georgian`
- `@fontsource-variable/noto-sans-armenian`
- `@fontsource-variable/noto-sans-devanagari`

Only the script-specific variable WOFF2 files are included in the site bundle.
