# Kiris Jobs

Личная офлайн-платформа рекрутера Oleksandr Kiris: каталог вакансий разных работодателей, анкета кандидата и прямой контакт в WhatsApp. Проект работает на GitHub Pages без серверной базы данных и после первого открытия может использоваться как PWA.

Текущий набор данных перенесён из каталога «Полный каталог вакансий Citronex 2026 — БРУТТО», актуализированного 23 июля 2026 года. Компания указывается как атрибут конкретной вакансии, но не является брендом платформы.

> Каталог открыт постоянно. Конкретный объект, дата выхода, график, жильё, право на оформление и индивидуальная ставка подтверждаются в прямом чате перед поездкой. Юридически обязательны договор и официальные документы, а не текст сайта.

## Что работает

- 14 вакансий в Польше, Венгрии и Бельгии;
- 11 языков: русский, украинский, польский, английский, азербайджанский, грузинский, индонезийский, испанский, филиппинский, непальский и армянский;
- каталог всех вакансий является главной страницей; поиск и фильтры помогают быстро выбрать нужную;
- у каждой вакансии есть постоянная страница `/vacancies/<id>/` с отдельным заголовком и описанием для публикации в Facebook;
- кандидат по ссылке открывает выбранную вакансию, смотрит условия, заполняет анкету и отправляет готовое сообщение рекрутеру в WhatsApp;
- 54 оптимизированные фотографии жилья с галереями по локациям Siechnice, Ryczywół, Bogatynia, Pruszcz Gdański, Budapest и Belgium;
- короткая мобильная анкета из четырёх шагов: контакт, место и документы, готовность и квалификация, проверка;
- локальный расчёт возраста из даты рождения без отправки данных на сервер;
- финальная кнопка копирует читаемую анкету и открывает WhatsApp с уже заполненным сообщением;
- уникальный номер каждой заявки и источник персональной ссылки;
- специальные вопросы для водителей C+E, UDT, бригадиров, механиков и профильных специалистов;
- проверка имени как в паспорте, города и служебных полей на ввод латиницей; комментарий можно писать на своём языке;
- предпросмотр и копирование готового сообщения до открытия WhatsApp;
- структурированное сообщение для рекрутера содержит все ответы кандидата, по одному полю в строке;
- установка как приложение и офлайн-доступ после первого успешного открытия;
- отсутствие аналитики, рекламных cookies и публичного сбора документов;
- автоматическая проверка структуры данных перед публикацией.

## Персональные ссылки

Параметр `src` добавляет источник в подготовленное сообщение WhatsApp, но не отправляет аналитику и не устанавливает cookies.

Примеры:

- украинский язык, Польша: `?lang=uk&country=poland&src=facebook_uk#jobs`;
- польский язык, без опыта: `?lang=pl&filter=no-experience&src=facebook_pl#jobs`;
- английский язык, водители: `?lang=en&filter=driver&src=tiktok_driver#jobs`;
- испанский язык, теплицы: `?lang=es&filter=greenhouse&src=whatsapp_es#jobs`.
- конкретная вакансия на украинском: `/vacancies/greenhouse-tomatoes/?lang=uk&src=facebook_uk`.

Источник можно назвать самостоятельно, используя латинские буквы, цифры, `_`, `-` или `+`.

Анкету можно заполнить офлайн. Для открытия WhatsApp и получения обновлений нужен интернет. Каталог, переводы и фотографии после первой загрузки доступны офлайн.

## Запуск

Нужен Node.js 20+ только для проверки и локального сервера:

```bash
npm test
npm start
```

Откройте адрес, который покажет сервер. Service worker не работает при запуске через `file://`.

## Обновление вакансий

Основной публичный контент находится в [`data/content.js`](data/content.js), переводы — в [`data/locales`](data/locales).

Перед изменением вакансии:

1. Подтвердите свободные места и дату заезда.
2. Подтвердите ставку именно **брутто**, валюту и период оплаты.
3. Проверьте объект, график, договор и условия жилья.
4. Проверьте право кандидата на легальное оформление для выбранной страны.
5. Синхронно обновите перевод вакансии во всех 10 дополнительных локалях.
6. Укажите дату проверки в `updatedAt`.
7. Запустите `npm test`.

Если менялся набор кэшируемых файлов, обновите `CACHE_VERSION` в [`sw.js`](sw.js).

## Публикация на GitHub Pages

1. Используйте публичный репозиторий `kiris-jobs`.
2. Загрузите ветку `main`.
3. В **Settings → Pages → Build and deployment** выберите **GitHub Actions**.
4. Workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml) проверит данные и опубликует сайт.
5. После успешной проверки GitHub Pages опубликует новую версию автоматически.

## Что создаёт доверие

- контакт реального рекрутера и понятные часы связи;
- все суммы указаны брутто, без выдуманного нетто;
- неподтверждённые ставки и места не маскируются под актуальные;
- количество часов, премии и международные командировки не обещаются;
- отдельно объяснены жильё, документы, этапы приезда и ограничения;
- кандидатам прямо сказано, что договор важнее каталога;
- на сайте нет вымышленных отзывов, счётчиков и «срочных» таймеров.

## Приватность

Репозиторий предназначен только для публичных вакансий и памяток. Не добавляйте сюда резюме, паспорта, карты побыту, телефоны кандидатов, заметки об интервью или выгрузки ATS: Git хранит историю.

GitHub Pages не является CRM. Персональные данные кандидатов должны храниться в отдельной защищённой системе с доступами, сроками хранения и процедурой удаления.
